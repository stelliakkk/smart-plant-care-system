# 当前硬件接线与验证边界

## S3引脚

| 设备/信号 | GPIO/供电 | 当前用途 |
|---|---|---|
| BH1750 SCL / SDA | 5 / 6 | I2C 100kHz，地址0x23，光照采样/自动补光 |
| BH1750 VCC / GND / ADDR | 原理图CN3为5V / GND / 低电平 | 模块供电按现有实物；I2C地址0x23，ADDR保持低地址 |
| 土壤湿度AOUT | 4，ADC1通道3 | 电压和相对百分比，上报；尚未完成实际盆土标定 |
| 盐分AOUT | 7，ADC1通道6 | 原始值/毫伏本地日志，无EC标定/上报 |
| DS18B20 DATA | 8 | 1-Wire，约4.7kΩ上拉到3V3，本地读取；不上报 |
| 补水泵MOS输入 | 9 | 20kHz PWM，开启50% |
| 施肥泵MOS输入 | 11 | 20kHz PWM，开启50%，当前清水演示 |
| 农药泵MOS输入 | 13 | 20kHz PWM，开启50% |
| 补光灯MOS输入 | 15 | 20kHz PWM，开启100% |
| 原生USB D−/D+ | 19 / 20 | 原生USB JTAG/串口，COM4对应S3 |
| 板载RGB | 38 | 当前板载灯配置 |

GPIO只连接MOS/驱动输入，不直接给泵供电。负载电源、驱动、板子和传感器共地；模拟输入须在3.3V允许范围内。按模块丝印和型号接线，不能仅按照片针脚顺序猜测。GPIO35～37在本N8R8模组涉及内部存储连接，应避免挪用。

湿度和盐分使用同一个ADC1单元，各自配置通道/校准；重复初始化不会重新占用ADC1。

## 开机与手动检查

四路初始化均关闭，旧上电运行5秒的验证函数/声明/调用已移除。确认接线后，可用网页短时手动动作观察实际泵/灯；泵单次最长30秒，手动灯可持续或定时最多10分钟；补水/施肥互斥、断网停止泵。自动补光可恢复保存的模式，但仍等待有效读数及持续阈值；开机不自动运行泵。

串口日志可查看BH1750读取、土壤raw/mV/%、盐分raw/mV、DS18B20值和heap。读数失败只告警并继续后续采样。heap是运行内存，应用分区余量是Flash，两者不同。

## 标定与清水演示

当前main/local_config.h的2200mV干/1100mV湿是已有参考端点，不代表已完成本次盆土标定。百分比为端点线性映射并限幅，不是绝对土壤含水率；0%不自动证明植物缺水。

实际使用前在目标盆土建立干湿参考，确认探头位置、方向和重复性；不要让电路/插头浸水，是否允许探头部分入水需按具体模块说明。两泵用清水测量相同PWM条件下运行固定秒数的体积，之后才用目标体积/流量换算时间。当前补水/施肥自动仅定时清水演示，不基于AI或湿度，施肥泵的代码名saltwater_pump不代表应使用食盐水。
