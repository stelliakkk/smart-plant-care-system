# 四路自动控制

## 初始状态与共同规则

四路自动模式首次均关闭，网页分别暂停/恢复；手动操作暂停对应模式，关闭全部暂停四路。后端SQLite保存期望模式、参数、冷却和最近100条判断事件；S3 NVS保存板端模式。服务单实例、单worker运行。

## 补光灯

S3基于BH1750本地控制：低于100 lux持续10秒开灯，高于300 lux持续30秒关灯，中间保持；读数无效或超过3秒未采样中断累计，10秒无有效读数关闭自动灯并报告异常。自动补光断网继续。模式改变先关闭灯再重新判断。光敏传感器避免灯具直射；实际阈值需现场确认。

## 农药泵

仅相邻定时照片分析done、pest_status=detected且pest_evidence非空可累计。疑似、未知、失败、设备离线、模式未确认或泵状态未知均清零；手动抓拍不计数。完成分析时照片超过180秒或拍摄间隔超过配置周期+60秒（最低360秒）不能构成连续检测。

连续两次符合条件下发spray/on/2000ms/source=auto；发布前持久化冷却预留。running从确认开启时冷却48小时，回执丢失或停止失败保留保守冷却；明确未发布、被拒绝或开启失败恢复此前冷却。手动喷洒也更新冷却，手动拒绝不会清除前一次真实喷洒的冷却。

冷却期间仍每300秒拍照分析、保留7天。冷却结束后只用新照片重新累计；服务/S3重启清零次数，旧照片不计入新周期。仅输出设置回执，不是实际喷出药量测量。

## 补水泵与施肥泵：定时清水演示

目前湿度未完成盆土标定、泵流量未测。两路逻辑定位为定时清水演示，不依赖AI/湿度/盐分，不显示估算毫升数，不设默认植物养护周期；三路泵已接线，但尚未完成实物运行测试。

| 参数 | 规则 |
|---|---|
| interval_sec | 必填整数，60～604800秒（1分钟～7天） |
| duration_ms | 必填整数，1～30000ms |
| 默认状态 | 自动关闭，参数为空，禁止直接启用 |
| 保存参数 | 保存后暂停对应自动模式，需主动恢复 |
| 恢复自动 | 从当前时刻起等待完整interval_sec，之后才第一次执行 |
| 周期到达 | 消费本次机会并将下次安排为当前时间+间隔，再检查/提交指令 |
| 另一泵忙/状态未知 | 跳过本次并记录原因，不等待、不补发 |
| 设备/MQTT离线或模式未确认 | 跳过并安排下一周期，不因恢复在线立即补发 |
| 后端或S3重启 | 保留模式/参数，重新等待完整间隔，不开机立即启动 |
| 手动操作 | 暂停对应定时泵，清空下次安排 |
| 同时到期 | 优先检查上次定时提交的另一泵；首次优先补水。成功提交一路后，另一路因互斥跳过，不排队补发 |

轮换依据last_scheduled_pump保存在SQLite的AutomationState中，发送MQTT前更新，重启后保留。明确发布失败或回执不明也保留已提交的轮次；仅离线、模式未确认等未提交的机会不推进轮次。只有一路到期时照常检查该路，不等待另一泵。相同周期持续同时到期且每次执行正常完成时，两路交替获得机会。

定时检查由后端每秒任务完成；S3只接有效的短时动作并本地计时关闭。参数与next_run持久保存，发送前记录执行机会和指令，回执不明时不重发该次。两泵手动/自动双重互斥；断网停止泵，关闭失败继续重试。

## 网页/API及兼容

GET /api/device/automation返回四路期望模式、board_modes、automation_ready、timed_pumps_ready、pump_schedules、光照/异常、虫害次数、冷却与事件。

POST /api/device/pump-schedule请求actuator=pump|fertilizer、interval_sec、duration_ms，保存并暂停。POST /api/device/automation请求actuator、enabled，支持四路；未配置定时参数启用返回400。

pump_schedules按两路保存interval_sec、duration_ms、next_run、last_command、last_reason，查询时附last_command_status。控制页显示已保存参数、模式、下次时间、跳过原因和回执，编辑中的输入不被周期刷新覆盖。

新增timed_pumps_ready标识，新后端不会向旧补光/喷洒固件发送定时泵或对应模式指令；原灯光/喷洒协议保留。启动会话变化与心跳更新在指令锁内处理，防止重启计时重置与定时到期竞态。

## 后续启用

本次轮换修复只涉及后端，无需为此烧录S3或CAM。重启后端并刷新网页后生效；板端仍须报告timed_pumps_ready=true。若板上尚无定时泵能力，再按[s3_partitions.md](s3_partitions.md)更新S3分区表与应用。填写清水演示参数、保存并点击恢复自动。

2026-11-02验证仅使用隔离数据库、模拟时钟和模拟MQTT，没有向实物发送测试指令。补光灯已由用户实测；三路泵已接线、逻辑已实现，运行效果仍待清水测试。已有灯光/农药48小时规则保留；实际水量、肥液浓度与植物周期需以后标定。
